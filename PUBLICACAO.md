# Publicação do dnconsultores-showcase

1. Confirme com a DN Consultores que os logótipos e fotografias podem constar do teu portefólio público.
2. Crie repositório **público** denominado `dnconsultores-showcase`.
3. Carregue os ficheiros deste ZIP, preservando as pastas.
4. Confirme a renderização das imagens no README.
5. Valide o site activo manualmente e acrescente capturas reais aprovadas em `screenshots/`.
6. Destaque o repositório no perfil GitHub.
